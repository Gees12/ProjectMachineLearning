## Cara Melihat Diagram

Semua diagram ditulis dalam **Mermaid**.

- **VS Code:** pasang ekstensi *Markdown Preview Mermaid Support*, buka file, tekan `Ctrl+Shift+V`.
- **GitHub:** diagram dirender otomatis saat file dibuka.
- **Ekspor gambar untuk laporan:** salin kode diagram ke [mermaid.live](https://mermaid.live), lalu unduh sebagai PNG/SVG dan simpan di folder ini.
